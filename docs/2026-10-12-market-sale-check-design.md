# 마켓 판매 점검 — 설계 (2026-10-12)

## 목적
가격세팅 xlsx를 넣으면 컴포넌트 상품이 마켓별로 판매중인지, 판매중이면 등재가·노출가가 세팅대로인지 한 화면에서 본다.

## 결정 사항(사용자)
- 방식: GitHub Pages 화면 + 크롬 확장(사용자 크롬에서 상품 페이지를 열어 읽음). 서버 수집·로컬 프로그램 방식은 기각.
  - 근거: 서버 요청에 G마켓·옥션·쿠팡 403, 스마트스토어 로그인 리다이렉트(2026-10-12 실측). 자사몰·하이마트만 열림.
- 판정: 등재가와 노출가를 둘 다 본다. 허용 오차 10원 이하(옥션 100원 단위 반올림, 하이마트 노출가가 세팅과 10원 차이 — 실측).
- 자사몰 = 슈퍼스토어(superstore.co.kr).
- 스마트스토어: 두 스토어(브랜드스토어 ihansung, 스마트스토어 acerstore)가 섞여 있고 엑셀에서 '에이서계정 등록' 칸 색으로 표시.

## 데이터
- `마켓별상품코드`: 모델명·마켓 코드(하이마트는 `하이마트온라인상품` 열 = 상세 페이지 goodsNo).
- `정산가세팅` 'G마켓 기준' 표: 마켓 블록(등재가(세팅)·노출가·정산액·차이). G마켓·옥션 노출가 기대값은 `노출가(2차혜택가)` 열(페이지 쿠폰 적용가와 같음, 실측), `최대혜택가` 도 함께 들고 있다.
- 두 시트는 모델명으로 잇는다.
- 원가·마진은 읽지 않는다.

## 판정 (칸 = 상품 × 마켓)
정상 / 가격 불일치(등재가·노출가 중 하나라도 10원 넘게 차이, 또는 못 읽음) / 판매 안 함(품절·중지) / 페이지 없음 / 수집 실패(봇 확인·로딩 실패) / 판매중·기준 없음 / 코드 없음.

## 범위 밖 · 남은 것
- 쿠팡: 엑셀 코드(예: 16368927311)로 상품 페이지가 열리지 않는다("상품을 찾을 수 없습니다") — 윙 등록상품ID로 보임. 쿠팡 상품 페이지 번호 또는 윙 조회 방법을 확인해야 한다. 기본 선택에서 뺀다.
- 컴퓨존: 코드가 모두 비어 있어 읽기 함수를 만들지 않았다.
